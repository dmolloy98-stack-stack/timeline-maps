# Timeline Maps

Side-by-side timeline maps comparing events, companies and eras on one shared axis.

- `index.html` – home page listing every map
- `console-wars/` – Xbox vs. PlayStation vs. Nintendo poster (PDF, PNG, data)
- `do-exclusives-sell-consoles/` – interactive yearly sales chart

To add a map: create a new folder with its own `index.html`, add a thumbnail to `assets/`, and add a card to the home page and a link to each page's top bar.
